# RL-PaO Code Sample

The core files, `optimization_model.py` and `train_pao.py`, were written by Jiahui Feng and implement the optimization model and RL training workflow. The remaining files provide supporting components for state compression and evaluation. The implementation uses Stable-Baselines3 and PySCIPOpt/SCIP.

Some experimental data are private. Datasets, preprocessing assets and trained models are not included, so this sample is provided for code review and cannot be run end to end.
